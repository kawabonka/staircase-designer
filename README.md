# 楼梯设计器 · 自建房/住宅

一个纯 HTML 的楼梯设计工具，无需安装，双击 `staircase-designer.html` 即可在浏览器中使用。

## 在线使用

<https://kawabonka.github.io/staircase-designer/staircase-designer.html>

## 功能

- 楼梯类型选择（直梯 / L 型转角梯）
- 基本尺寸参数设置（踏步宽、高、梯宽、层高等）
- L 型转角自定义（休息平台、转角踏步）
- 净空与撞头提示
- 住宅规范校验（参考 GB 50352）
- 平面图、剖面图、3D 视图与排砖/构件表

## 本地使用

直接用浏览器打开 `staircase-designer.html` 即可，所有数据都在本地计算，不上传任何信息。

## 发布

本页面通过 GitHub Pages 发布，由 `main` 分支根目录直接托管。
